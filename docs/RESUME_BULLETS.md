# Resume Bullets: Singapore Banking Loan Portfolio & Sector Exposure Analytics

- Built an end-to-end analytics pipeline in Python and DuckDB SQL on 62 months of official MAS/Singapore DOS commercial bank lending data (~S$966B portfolio), using joins, CTEs, and window functions to quantify YoY growth, sector concentration, and each industry's contribution to S$67.4B in net business loan growth.
- Designed a star-schema Power BI data model with 24+ DAX measures and built a two-page interactive dashboard surfacing validated findings, including 60.22% business-lending share and 76.87% top-3 sector concentration, cross-checked against independent SQL results for accuracy.
